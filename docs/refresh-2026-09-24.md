# Bold juice-bar redesign

Design references reviewed: Jamba (https://www.jamba.com/menu), Boost Juice (https://www.boostjuice.com.au/), and JOE & THE JUICE (https://www.joejuice.com/?market=uk). Original implementation, not copied branding or assets.

- Bold DM Sans display typography, citrus/coral/cream identity, outlined buttons and photo frames.
- Larger product names, prices, Arabic labels and touch targets; three desktop columns, two tablet columns, one phone column.
- Restyled navigation, hero, category banner, filters, search, cards, footer and cart.
- Intro replays on reload, without a session-storage gate. Explicit skipIntro, reduced-motion and data-saver bypasses remain. Same local four-second footage, with a light branded frame, warm CSS color treatment and shared theme tokens.
- Existing menu prices, category gestures, photos and WhatsApp cart behavior retained.
- Production build and six unit tests passed. Browser coverage checks checkout, popup failure handling, cart clearing, category/search behavior, media, intro replay, reduced motion and navigation on desktop and mobile. Screenshot checks at 320/390/768/1440px show no horizontal page overflow.

Theme: src/refresh.css. Visual capture: node scripts/capture-refresh.mjs (requires development server on port 5173).
